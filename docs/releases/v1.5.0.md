# v1.5.0 — Chapter-directory downloads and per-manga policy

## Chapter directory

- The separate Download management screen and download-status filter are removed.
- Opening a manga focuses the first unread chapter.
- Download controls remain in the chapter title menu, including selection,
  Download options, Auto-download, pause/resume, cancellation, delete-read, and
  delete-all-downloaded actions.

## Per-manga deletion

- Each manga can override the global delete-after-mark-read policy.
- Each manga can override the finished-chapter retention policy.
- Overrides apply to manual reads, reader close, and background cleanup.
- Removing a manga from the Library disables its automation and deletes its
  recorded local chapter files after the server removal succeeds.

## Browse languages

- Source-language selection is persisted across KOReader restarts.
- Chinese is the default source-language filter when no saved selection exists.
